# 副業プロジェクト運営テンプレート（Claude Code向け）

Claude(AI)に企画・執筆・進捗管理・分析などの役割を分担してもらいながら、1人で副業・情報発信プロジェクトを運営するためのフォルダ構成テンプレートです。
「支払いを伴う方法は使わない（サーバー契約・従量課金・買い切りソフトなし）」という制約のもとで、実際に運用しているものをベースにしています。

## フォルダ構成
```
00_プロジェクト管理/   … 事業案・プロジェクト計画書・レビューチェックリスト
01_市場調査/           … 市場調査レポート置き場
02_設計/               … 支援ツールの設計ドキュメント（クラス図など）
03_コンテンツ制作/     … 記事・原稿の置き場（プラットフォームごとにサブフォルダを作る）
04_プログラム/         … コンテンツ管理・進捗トラッカー、投稿補助スクリプト
05_評価・分析/         … 売上・PVの記録、評価テンプレート、日次運用手順
07_セキュリティ確認/   … 公開前の個人情報・著作権チェックリスト
08_行動記録/           … やったことを時系列で記録するログ（企画立案の材料にする）
```

## 使い方
1. このリポジトリをそのままコピーして、自分のプロジェクト用フォルダにする
2. `00_プロジェクト管理/プロジェクト計画書_テンプレート.md`をコピーして、自分の目標・制約に書き換える
3. Claude Code（またはお使いのAIコーディングツール）にこのフォルダ構成を読み込ませ、「このプロジェクトの役割分担に沿って動いてほしい」と伝える
4. コンテンツを公開する前は、必ず`07_セキュリティ確認/チェックリスト.md`と`00_プロジェクト管理/レビューチェックリスト.md`の両方を確認する

## このテンプレートの考え方
- **役割分担**: ビジネス提案・PM・レビュラー・市場調査・企画・プログラマー・ライター・評価者・セキュリティ担当、のように役割を分けて動く
- **記録を残す**: `08_行動記録`に何をしたかを都度残すことで、次の企画をゼロから考えなくてよくなる
- **公開前チェックは2種類**: 「公開して問題ないか」（セキュリティ・著作権）と「狙いを達成できているか」（レビュラー）は別物として、両方チェックする
