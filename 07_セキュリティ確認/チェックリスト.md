# セキュリティ・著作権チェックリスト

担当役割: セキュリティ・著作権チェック担当
運用ルール: **公開（投稿・価格設定・SNS投稿など、外部に公開する操作）の前に必ずこのチェックを行い、結果を`07_セキュリティ確認/チェック結果_<コンテンツ名>.md`として残す。**

## チェック項目

### 個人情報
- [ ] 本文・プロフィール・画像に、本名／メールアドレス／電話番号／住所が含まれていないか
- [ ] スクリーンショットを使う場合、画面内に個人情報・社外秘情報が写り込んでいないか
- [ ] 家族・勤務先など第三者を特定できる情報が含まれていないか

### 著作権・引用
- [ ] 他サイト・他記事の文章をそのままコピーしていないか（要約・自分の言葉での言い換えになっているか）
- [ ] 引用する場合、出典を明記しているか
- [ ] 画像・図・コードを他者の著作物から流用していないか（自作または利用規約上問題ないものか）
- [ ] コードにライセンス上問題のある外部コードの無断転載がないか

### アカウント・認証情報
- [ ] パスワード・APIキー・トークンなど機密情報が本文やスクリーンショットに写っていないか

### 規約・プラットフォームリスク
- [ ] 販売するコンテンツが、各プラットフォームの利用規約・禁止事項（誇大広告、断定的な収益保証表現など）に抵触していないか
- [ ] 「必ず稼げる」等の誇大な表現になっていないか

## 判定
- 問題なし → 公開してよい
- 要修正 → 該当箇所を修正後、再チェック
- 保留 → 本人確認が必要
