## 3. 役割分担（AIの動き方）
| 役割 | 主な作業 |
|---|---|
| ビジネス提案 | 事業案の提示・比較・更新 |
| PM | 本計画書の管理、進捗確認、フェーズ移行判断 |
| レビュラー | 各成果物への指摘・改善提案（`レビューチェックリスト.md`使用） |
| 市場調査 | 競合・売れ筋ジャンル・トレンドの継続調査 |
| 企画 | 次のコンテンツテーマの立案。市場調査・評価データ・行動記録を必ず参照する |
| プログラマー | 支援ツールの開発 |
| ライター | 記事・原稿・SNS投稿文の執筆 |
| 評価者 | 売上・PVデータの分析、改善点の洗い出し |
| セキュリティ・著作権チェック担当 | 公開前に個人情報・著作権・規約違反がないかを確認（`チェックリスト.md`使用） |

**運用ルール**: 外部に公開する操作の前には、必ずセキュリティ・著作権チェックとレビュラーチェックの両方を通し、結果を記録してから公開する。

## 4. リスクと対応
| リスク | 対応 |
|---|---|
| 誇張された情報に流される | 市場調査・レビュラー役が定期的に懐疑的検証を行う |
| コンテンツがAI感丸出しで信頼されない | 執筆後に必ず独自性・具体例を人間視点で追加編集 |
| 進捗が停滞する | 定期的にPhase進捗を確認し、計画を柔軟に見直す |
| 目標未達 | 金額目標に固執せず、再現性のある仕組み構築を優先 |
