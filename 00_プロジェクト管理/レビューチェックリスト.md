# レビュラー チェックリスト

担当役割: レビュラー
運用ルール: **公開前は、`07_セキュリティ確認/チェックリスト.md`（個人情報・著作権・規約）に加えて、必ずこのチェックも行う。どちらか一方だけでは公開しない。**

セキュリティ・著作権チェックは「公開して問題ないか」を見るものだが、こちらは**「その企画が本来の目的を達成できているか」**を見るためのもの。

## チェック項目

### 企画との整合性
- [ ] 企画書に書いた「狙い」「差別化ポイント」が、実際の本文に反映されているか
- [ ] 想定していた導線（他プラットフォームへのリンク、CTAなど）が、本文に実際に含まれているか
- [ ] シリーズものの場合、前回までの記事との整合性・つながりがあるか

### 読者視点
- [ ] タイトル・見出しは、狙った読者に刺さる訴求になっているか
- [ ] 読み終えた後、読者が次に取ってほしい行動が明確か
- [ ] 説明が独りよがりになっておらず、初見の読者にも伝わる書き方か

### 目的の再確認
- [ ] このコンテンツを出す目的は何だったか、それを達成する構成になっているか
- [ ] 目的を達成する上で欠けている要素がないか（リンク・CTA・比較対象など）

## 判定
- 問題なし → 公開してよい
- 要修正 → 該当箇所を修正後、再チェック
